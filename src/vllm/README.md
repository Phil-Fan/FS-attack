# vLLM 代码修改

This folder is used to modify the source code of vLLM, add some functions, such as monitoring and analysis.

- `file_operations.py` is used to copy the code to the source code of vLLM, making it easier to modify later.
- `file_list.csv` records the code mapping relationship.

## vLLM on DGX Spark

Use [eelbaz/dgx-spark-vllm-setup](https://github.com/eelbaz/dgx-spark-vllm-setup) to setup vLLM on DGX Spark.
